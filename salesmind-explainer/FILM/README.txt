SalesMind film - how to build it
--------------------------------

1. You have already done the hard part by extracting this zip.
2. Double-click  Make_Film.bat  in this folder.
3. The finished film appears in your Videos folder:
   SalesMind_The_RM_Operating_System.mp4  (17 chapters, about 19 minutes)

If Windows asks for permission to install FFmpeg, click Yes.
Every name, number and screen in the film is synthetic.
